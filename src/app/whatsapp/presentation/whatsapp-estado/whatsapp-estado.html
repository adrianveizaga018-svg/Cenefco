Cómo iniciar el servicio en producción (VPS)
1

Instalar dependencias

cd /srv/cenefco/cenefco-admin/whatsapp-service && npm ci --production

2

Configurar variables de entorno

Crear el archivo .env con DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD apuntando a PostgreSQL.

3

Iniciar con PM2

pm2 start src/index.js --name cenefco-bot && pm2 save

4

Ver logs en tiempo real

pm2 logs cenefco-bot

Formato esperado

El JSON debe ser un array de objetos con esta estructura: 

[
  {
    "url": "https://cenefco.com/curso-slug",
    "curso": "NOMBRE DEL CURSO",
    "mes": "ENERO 2025",
    "estudiantes": [
      "Nombre Apellido",
      "Otro Participante"
    ],
    "status": "ok"
  }
]
  • Solo se importan cursos con status: "ok"
  • El slug se extrae automáticamente de la URL
  • Los nombres duplicados de estudiantes se eliminan automáticamente
  • El campo mes se guarda como período y se extrae el año como gestión
